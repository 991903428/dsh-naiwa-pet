奶蛙桌宠 · 增强版   使用说明
================================================

一、启动
  双击 bin 文件夹里的「奶蛙桌宠.exe」。
  奶蛙会站在屏幕右下角，左键点它会笑，右键点它会弹出菜单。
  只允许运行一个：再次双击只是把它叫回屏幕。

二、左键（主要玩法）
  单击奶蛙       默认播放原版笑声 + 捧腹大笑（约 14 秒），笑完躺在地上
  笑倒后再单击   翻身站起来
  按住左键拖动   拖到桌面任意位置，松手会轻轻弹一下，位置会记住
  一点就笑，不需要双击。
  想换成「戳肚子」：右键菜单第一行「左键动作 · 捧腹大笑」，点一下就会切成
  「左键动作 · 戳肚子」，再点一下切回来。这行文字就是当前状态，会记住，
  下次启动仍生效。

  两种左键动作的手感不一样：
    · 戳肚子    可以连点，点得越快肚子弹得越欢，一次点一下
    · 捧腹大笑  点一下就完整播 14 秒，播放中再点不会重来
                （想打断就右键「停止大笑 / 站起来」）

三、右键菜单
  左键动作 · 捧腹大笑 / 戳肚子
                     点一下切换左键单击做什么，行文字就是当前状态
  停止大笑 / 站起来  立刻停下，或者把躺着的奶蛙叫起来
  查看余额           在奶蛙头顶弹出余额卡片
  原版笑声           开 / 关音效（打勾表示开）
  大小 → 小号 / 标准 / 大号
  总在最上面         关掉后会藏在其他窗口后面
  全屏时自动隐藏     看视频、玩游戏时自动让开（打勾表示开）
  关于奶蛙           作者与许可信息
  取消桌宠（退出）   关闭程序

  余额卡片打开后：左键单击卡片 = 刷新；右键单击卡片或点「关闭」= 收起。
  卡片 30 秒没有操作会自动收起，不会挡着桌面。

  菜单出现在鼠标位置；点菜单以外的地方（桌面、别的窗口、奶蛙身上）它就会收起，
  再点一次右键也一样收起。

四、查看余额（自动读取已登录的 DeepSeek 账号）
  不用填任何 Key：只要这台电脑上的 DeepSeek Harness 登录过 DeepSeek 账号，
  奶蛙会直接读取 Harness 保存的登录凭据，调用 platform.deepseek.com
  官方接口，把该账号的余额显示出来。

  · 余额就是 Harness 账户页里的那笔钱（充值余额 + 赠送余额）
  · 凭据只在本机读取，也只发给 platform.deepseek.com，不经过第三方
  · 卡片上会显示账号名、余额、赠送/充值明细和更新时间
  · 在 Harness 里退出登录后，卡片会显示「未登录」并提示重新登录
  · 打开卡片时自动刷新；左键点卡片或点「刷新」可再刷一次

  （可选）想改用 API Key 或自建接口：
  第一次打开「查看余额」时，程序会在 exe 旁边生成 config.json。
      "apiKey": "sk-你的key"      填了就用 Key 直连，优先于 Harness 账号
      "provider": "custom"        接自建 / 中转接口
      "customUrl": "https://example.com/api/balance",
      "customLabel": "我的接口",
      "customHeader": "Authorization",
      "customHeaderValue": "Bearer {key}",
      "customJsonPath": "data.balance"
  保持 apiKey 为空、provider 为 auto，就是默认的「跟随 Harness 账号」。
  customJsonPath 用来指定金额字段；留空则会依次尝试
  data / result / payload 里的 total、balance、amount 等常见字段。

五、托盘图标
  任务栏右下角有奶蛙图标：双击 = 把奶蛙叫回屏幕，右键 = 同一个菜单。
  如果图标被折叠到「^」里，拖出来即可。

六、文件说明

七、常见问题
  · 没有声音      菜单里确认「原版笑声」是打勾的，并检查系统音量与输出设备。
  · 显示「未登录」  先在 DeepSeek Harness 里登录 DeepSeek 账号；
                    或者在这个 config.json 里填 apiKey。
  · 显示「获取失败」卡片上会写明原因（登录过期 / 网络或 TLS 失败 / 返回格式不对）。
                  提示「TLS 连接被系统拒绝」时：别从受限终端或沙箱里启动，
                  直接双击 bin 里的「奶蛙桌宠.exe」，或检查系统时间与代理软件。
  · 卡片按钮没反应  本版已修复（旧版点击会穿透）；请用 bin 里最新编译的程序。
  · 全屏时消失     「全屏时自动隐藏」在起作用，菜单里可以关掉。
  · 找不到奶蛙     双击托盘图标，奶蛙会回到屏幕右下角。
  · 想换机器       整个 bin 文件夹拷走即可；新机器登录 Harness 后余额自动可用。
  · 左键变戳肚子了  菜单第一行「左键动作 · 戳肚子」再点一下，切回捧腹大笑。
  · 关掉 DSH 后它还在？ 作为插件运行时不会：插件每两秒写一次心跳，
                    DSH 一关（哪怕强制结束）心跳就停，奶蛙最多十秒自己离开桌面。
                    只有在单独双击 exe 运行、或系统把 DSH 冻住时才需要手动右键退出。
